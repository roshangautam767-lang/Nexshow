# NexShow web app (Phase 2)

1. Install Node.js 18.18 or newer (https://nodejs.org).
2. In this folder: `npm install`
3. Copy `.env.example` to `.env.local` and put your TMDB key in `TMDB_API_KEY`.
4. `npm run dev` and open http://localhost:3000

Without a TMDB key the site still loads and shows a clear "movie data unavailable" message.
